## 2. 数据流（一帧的生命周期）

```
相机 1280x480 ──split──▶ left 640x480 + right 640x480
                              │
                    ① 校正（rectify_before_infer=true）
                       depth_utils.load_rectifier().rectify_pair()
                              │  去畸变 + 行对齐
                              ▼
                    ② FFS 推理 stereo_depth.FFSDepthEstimator.infer()
                              │  输出 disparity（模型分辨率，如 0.5 档=240x320）
                              ▼
                    ③ 深度换算 depth_utils.disparity_to_depth()
                       depth = fx·B / (disp × 1.0221)      ← 1.0221 是实测的视差校正
                              │  外推过滤 + 散斑过滤
                              ▼
                    ④ 点云 pointcloud.PointCloudBuilder.build()
                       x=(u-cx)z/fx, y=(v-cy)z/fy, z=深度      ← y 向下
                              │
                    ⑤ 显示 viewer.StereoViewer.show_panels() / Open3D 或纯 numpy
```

**关键约定**（踩过的坑，全项目统一）：
| 项 | 约定 |
|---|---|
| 图像 | **BGR** uint8，单眼 640×480 |
| 深度 | `float32` **米**，无效 = 0，另给 `valid` 掩码 |
| 点云 | `float32` 米，相机系，**y 向下**（显示时才翻）|
| 时间 | `time.perf_counter()` 秒 |
| 视差 | 模型分辨率，**不等于**图像尺寸 |

## 3. 标定链路（阶段 5，已完成）

```
tools/capture_calib.py --capture    采集标定图（玻璃板 12x9/3.0mm，9~17cm）
        │  output/calib/<时间戳>/
        ▼
tools/run_calibration.py            计算 + 验证极线 + 写 calibration/stereo_calib.yaml
        │  双目 RMS 0.1246 px，基线 64.891 mm，校正后 fx 547.02
        ▼
depth_utils.load_rectifier()        运行时读 yaml → 校正映射表
```

另有一条**跨相机对齐**支线：`tools/aruco_align.py`（ChArUco 板 5x7/36mm 给位姿 →
把点云变换到板坐标系 → 与 RealSense 对比），见 `tools/compare_with_realsense.py`。

## 4. 性能现状（阶段 7 实测）

| 环节 | 耗时 | 备注 |
|---|---|---|
| 采集 | 51.6 FPS（DSHOW）/ 58.8 FPS（MSMF） | 不是瓶颈 |
| 校正 | 0.6 ms | 可忽略 |
| **推理** | **164 / 95 / 47 ms**（scale 1.0 / 0.75 / 0.5） | **唯一大头，占 82%** |
| 点云构建 | 23 / 10 / 4 ms | 随 scale 平方下降 |
| 显示合成 | 12 / 6.6 / 3.4 ms | 同上 |

三档预设（`tools/bench_presets.py` 实测精度）：

| 预设 | scale/iters | 三线程 FPS | 平均深度误差 |
|---|---|---|---|
| 精确 | 1.0 / 8 | 6.2 | 0.18% |
| 平衡 | 0.75 / 8 | 10.3 | 0.19% |
| 快速 | 0.5 / 4 | **20.6** | 0.19% |

## 5. 要加东西，加在哪？

| 想做的事 | 改哪里 |
|---|---|
| 加一个可调参数 | `config.yaml` + 读它的模块（`main.py` / `stereo_sdk/session.py`）|
| 换采集分辨率 / 后端 | `camera.py` + `config.yaml`（⚠️ 改分辨率必须重标定）|
| 换推理档位 | `config.yaml` 的 `ffs.scale` / `ffs.valid_iters` |
| 加一种新的深度后处理 | `depth_utils.py`（纯函数，好测）|
| 加保存格式 | `pointcloud.py`（PLY）/ `depth_utils.save_depth_npy` |
| 加显示面板 | `viewer.py`（面板数组由调用方拼）|
| 给 GUI 暴露新能力 | **只加在 `stereo_sdk/session.py`**，别让 GUI 碰内部模块 |
| 加标定板类型 | `calibration.py` 的 `BoardSpec` + `tools/capture_calib.py` |
| 加自动化测试 | `tests/`（目前自检在 `tests/test_pipeline_offline.py`）|

## 6. 不要碰的

| 路径 | 原因 |
|---|---|
| `third_party/Fast-FoundationStereo/` | 官方推理代码，改了没法复现；升级靠替换整个目录 |
| `weights/` | 67 MB 权重，不入库 |
| `calibration/*.yaml` | 运行时只读；要换标定就重新跑 `run_calibration.py` |
| `output/captures/` | 真实测量数据，测试请用 `_work/` 或自检临时目录 |
