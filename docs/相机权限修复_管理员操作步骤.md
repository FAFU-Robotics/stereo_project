## 使用规则（很重要）

1. **做完一步，立刻验证一次**；出现 `[结论] ✅ 拿到真实画面！` 就**停止**，不用做后面的步骤。
2. 验证方式（**双击即可，不需要管理员**）：

   看最后几行的 `Exit code`：`0 = 成功`、`3 = 仍被拒绝`、`5 = 建图成功但没帧`。
3. 全程**不卸载软件、不删除你的数据**；每一步都写了"如何恢复"。
4. 把每一步的结果（截图或文字）发我，我继续判断。

## 如何打开"管理员终端"

- 按 **Win + X** → 选 **"终端(管理员)"** 或 **"Windows PowerShell(管理员)"**；
- 或按 **开始键** → 输入 `cmd` → 在"命令提示符"上**右键** → **以管理员身份运行**；
- 成功的标志：窗口标题里带 **"管理员"** 字样。

---

## 步骤 0：相机隐私开关，关掉再打开（**不需要管理员**）

1. **设置 → 隐私和安全性 → 相机**
2. 找到最下面的 **"让桌面应用访问你的相机"** → 把开关**关掉**
3. **等 5 秒**，再**打开**
4. 顺便确认上面两项（"相机访问"、"让应用访问你的相机"）都是**开**
5. 立刻跑一次 `tools\相机状态检查.bat`

> 原理：注册表里读出来是 `Allow`，但**有效状态可能已损坏**。关/开一次会强制 Windows 重写授权记录。
> 恢复：这个开关本身没有任何副作用，保持打开即可。

---

## 步骤 1：重启相机帧服务器（**需要管理员**）

在管理员终端里逐条执行：

```cmd
sc query FrameServer
net stop FrameServer
net start FrameServer
sc query FrameServer
```

最后一条应显示 `STATE : 4 RUNNING`。

然后立刻跑一次 `tools\相机状态检查.bat`。

> 恢复：不需要（服务本来就是按需启动，停止/启动无副作用）。

---

## 步骤 2：把两个相机"禁用 → 启用"一遍（**需要管理员**，最可能有效）

这相当于"拔插"但不动物理线，用来**清除设备卡死状态**。

```cmd
pnputil /disable-device "USB\VID_0BDA&PID_5883&MI_00\6&d574a2&0&0000"
timeout /t 3 >nul
pnputil /enable-device  "USB\VID_0BDA&PID_5883&MI_00\6&d574a2&0&0000"

pnputil /disable-device "USB\VID_0408&PID_548D&MI_00\6&37a6916b&0&0000"
timeout /t 3 >nul
pnputil /enable-device  "USB\VID_0408&PID_548D&MI_00\6&37a6916b&0&0000"
```

（第一条 = DECXIN，第二条 = 笔记本内置相机）

然后跑 `tools\相机状态检查.bat`。

### 如果上面命令报"找不到设备"，改用图形界面：

1. **设备管理器**（Win+X → 设备管理器）→ 展开 **"照相机"**
2. 右键 **"USB Camera"** → **卸载设备** → ⚠️ **不要**勾选"删除此设备的驱动程序软件" → 确定
3. 菜单 **操作 → 扫描检测硬件改动**，设备会重新出现
4. 对 **"HP True Vision FHD Camera"** 重复一次
5. 跑 `tools\相机状态检查.bat`

> 恢复：只是重装驱动枚举，无副作用；驱动文件没有删除。

## 步骤 3：先做"拔插 A/B 测试"（不需要管理员，但需要动手）

1. 跑一次 `tools\相机状态检查.bat`，记下设备列表（应有 3 个：HP True Vision / USB Camera / OMEN Cam & Voice）
2. **拔掉 DECXIN 的 USB 线** → 再跑一次 → **"USB Camera" 应从列表里消失**
3. 把 DECXIN **插到机身另一个 USB 3.0 口（蓝色/SS）直接插**，不要经扩展坞/延长线 → 再跑一次
4. 把这个过程中的检测结果发我

> 目的：① 确认 `USB Camera` 就是 DECXIN；② 排除 USB 带宽/供电问题。

## 步骤 4：临时停用 HP OMEN 的相机组件（**需要管理员**，最后再试）

HP 的相机内核驱动与服务仍在运行（`HPOmenCustomCapDriver` + `OmenCap`）。

```cmd
sc query HPOmenCap
sc stop  HPOmenCap
sc query HPOmenCustomCapDriver
sc stop  HPOmenCustomCapDriver
```

然后跑 `tools\相机状态检查.bat`。

> **恢复方法（务必记下）**：
> ```cmd
> sc start HPOmenCustomCapDriver
> sc start HPOmenCap
> ```
> 如果 `sc start` 报错，重启电脑即可完全恢复（这两个组件本来就是自动/按需启动）。

## 步骤 5：厂商与系统层（如果以上都无效）

1. **联系 HP 支持**：说明"Windows 相机 App 能用 DECXIN，但所有桌面程序（OpenCV 等）访问物理相机
   都被拒绝（E_ACCESSDENIED），重启与隐私开关无效"。
2. **检查 BIOS/UEFI 里是否有相机相关开关**（HP OMEN 机型常有摄像头隐私/禁用选项）。
3. 确认 **F8 / Fn+F8 摄像头隐私键**没有处于"已屏蔽"状态（指示灯）。
