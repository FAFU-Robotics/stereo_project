# 安装指南

本文档给出两条互斥的安装路线。先看这张表决定走哪条，再跳转对应章节。

| | 路线 A：直接用 EXE | 路线 B：从源码运行 |
|---|---|---|
| 适合谁 | 只想拿到深度图和点云 | 要改代码、写 SDK 程序、重新打包 |
| 需要装 Python | 不需要 | 需要 |
| 需要装 CUDA Toolkit | 不需要 | 不需要 |
| 体积 | 约 5.0 GB（含运行库与权重） | 约 4.5 GB（主要是 torch 与权重） |
| 可调参数 | 改 `config.yaml` | 改源码与 `config.yaml` |
| 首次可用耗时 | 解压即用 | 15~40 分钟（取决于网速） |

> 两条路线都要求：64 位 Windows 10/11、NVIDIA 显卡与较新驱动、Visual C++ 2015–2022 x64 运行库、一支 UVC 双目相机。

---

# 路线 A：直接用 EXE

## A1. 取得安装包

EXE 交付物不进 Git 仓库（体积 5.0 GB、15761 个文件），改由 GitHub Releases 以分卷形式发布。

1. 打开本仓库的 **Releases** 页面。
2. 下载 `StereoCamera-v0.3.0.7z.001`、`.002`、`.003` **全部三个文件**（版本号随发布变化），放在同一个目录。
3. 校验（可选但推荐）：页面上给出的 `SHA256SUMS.txt` 一并下载，在 PowerShell 里执行
   ```powershell
   Get-FileHash .\StereoCamera-v0.3.0.7z.001 -Algorithm SHA256
   ```
   与文件中的值逐字符比对。

## A2. 解压

1. 安装 [7-Zip](https://www.7-zip.org/)（Windows 自带解压不支持分卷 7z）。
2. 右键 `StereoCamera-v0.3.0.7z.001` → **7-Zip → 提取到当前位置**。只对第一卷操作，其余卷会被自动接上。
3. 得到 `StereoCamera` 文件夹，其中至少有：`StereoCamera.exe`、`config.yaml`、`calibration\`、`weights\`、`_internal\`。

> **不要只把 exe 拷出来。** 程序依赖同级的 `config.yaml`、`calibration\`、`weights\` 与 `_internal\`；单独一个 exe 会在启动时报“找不到权重或 config”。
>
> 解压路径可以含中文，但**不要放在需要管理员权限才可写的目录**（如 `C:\Program Files`），否则保存图像与日志会失败。

## A3. 检查前置条件

| 检查项 | 做法 | 期望 |
|---|---|---|
| 显卡驱动 | 命令行执行 `nvidia-smi` | 能列出显卡与驱动版本，CUDA Version ≥ 12.8 |
| VC++ 运行库 | 直接启动程序 | 若提示缺 `VCRUNTIME140.dll`，安装 Microsoft Visual C++ 2015–2022 Redistributable (x64) |
| 相机 | 设备管理器 | 出现 UVC 摄像头设备；本项目验证机型为 DECXIN（标定基于索引 1） |

## A4. 启动与验证

1. 双击 `StereoCamera.exe`，直接进入主界面 **Stereo Viewer**（不弹 UAC，**不需要管理员权限**）。
2. 先点左侧「**环境自检**」。全部项显示 `[OK]`、且 `CUDA 可用=True` 才算环境就绪。
3. 点右上角「**开始串流**」，状态变为「串流中」后，在 `2D` 标签勾选「彩色」确认左右画面不是全黑。
4. 勾选「深度」，或切到 `3D` 标签看点云。首次进深度/点云会加载模型，需要数秒。
5. 要做标定，点左侧「**标定工作台**」；它会先停串流再把相机交给四页式界面。

完整说明见 [软件使用说明.md](软件使用说明.md)。

# 路线 B：从源码运行

以下命令都在**仓库根目录**（含 `config.yaml` 与 `pyproject.toml` 的那一层）执行。

## B1. 选择并确认 Python 解释器

`pyproject.toml` 声明的下限是 Python 3.10，本项目实测版本为 **3.14.6**。

```bat
where python
python -c "import sys; print(sys.version)"
```

> **这一步最容易出错。** 机器上常装有多份 Python（IDE 自带、系统商店版、独立安装版）。若 `where python` 列出的第一个不是你要用的那个，后续所有命令都会装到错误的解释器里。此时请**写全路径**，例如：
>
> ```bat
> "C:\Users\<你>\AppData\Local\Python\pythoncore-3.14-64\python.exe" -m pip install ...
> ```

## B2. 先装 PyTorch（顺序不能反）

`requirements.txt` 里钉的是 `torch==2.9.1` / `torchvision==0.24.1`，但**默认 PyPI 提供的是 CPU 版**。必须先从 cu128 索引装一次，再用 `requirements.txt` 补其余依赖，否则会得到一个跑不了 CUDA 的 torch。

```bat
python -m pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cu128
```

版本选择的依据（选错会怎样）：

| 你的情况 | 该装什么 | 选错的后果 |
|---|---|---|
| RTX 50 系（Blackwell，sm_120） | **必须** cu128 及以上（本项目实测 2.9.1+cu128） | cu124 及更早的轮子不含 sm_120 内核，运行时报 `no kernel image is available for execution on the device` |
| Python 3.14 | 只有 2.9.0 / 2.9.1 的 cu128 线提供 cp314 轮子 | 更早版本会报“找不到匹配的发行版” |
| RTX 30/40 系 | cu121 / cu124 均可（自行确认对应的 torch 版本） | 一般可用，但仍建议 cu128 与本文档保持一致 |

验证：

```bat
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

期望输出形如 `2.9.1+cu128 True NVIDIA GeForce RTX 5060 Laptop GPU`。

## B3. 装其余依赖

```bat
python -m pip install -r requirements.txt
```

`requirements.txt` 的每一条都带注释说明“为什么需要它”，其中两条值得单独提醒：

- **`omegaconf` 必须装**。FFS 的权重文件里内嵌了 `DictConfig`，`torch.load` 反序列化时需要它；但源码里并不 `import omegaconf`，缺了会直接报 `ModuleNotFoundError`。
- **`plotly` 与 `dash` 必须与 `open3d` 同时装**。`import open3d` 在顶层就会加载 `open3d.visualization.draw_plotly`，缺一个就点云窗口起不来。

国内网络较慢时可加镜像参数，例如：

```bat
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## B4. 下载模型权重

权重约 68 MB（`model_best_bp2_serialize.pth` 67.8 MiB + `cfg.yaml`），不入库。用仓库自带脚本下载：

```bat
python tools\fetch_ffs_weights.py
```

该脚本只用 Python 标准库，因为本机实测 PowerShell / .NET 与 git 的 TLS 通道会失败（详见 [常见问题.md](常见问题.md)）。常用参数：

| 参数 | 作用 |
|---|---|
| `--dest <目录>` | 改下载目标目录（默认 `weights\23-36-37`） |
| `--list` | 只打印文件 ID 与目标路径，不下载 |
| `--only <文件名>` | 只下载指定的那一个文件 |
| `--skip-verify` | 跳过下载后的完整性检查 |

也可用浏览器手动下载，但**目录结构与文件名必须一致**：

```
weights/23-36-37/
├── cfg.yaml
└── model_best_bp2_serialize.pth
```

## B6. 启动

| 目的 | 命令 |
|---|---|
| 主界面（等价于双击 EXE） | `python app_entry.py` |
| 只做界面自检（不连相机） | `python app_entry.py --gui-selftest` |
| 标定工作台 | `python app_entry.py --gui` |
| 实时预览 | `python main.py` |
| 实时视差 | `python main.py --mode depth` |

## B7. 装成 Python 包（可选）

如果要在自己的项目里 `import stereo_sdk`：

```bat
python -m pip install -e .
```

```python
from stereo_sdk import Session
```

注意：`pip install -e .` 会把根目录的 `camera` / `calibration` / `stereo_depth` 等模块一并装进 site-packages（`pyproject.toml` 的 `py-modules` 段列出了清单），因此**不要手动拷贝 `stereo_sdk/` 目录**，那样必然报 `ModuleNotFoundError: camera`。

# 环境变量

程序内部会自行设置下列变量，**正常情况下不需要手动设**：

| 变量 | 值 | 原因 |
|---|---|---|
| `TORCHDYNAMO_DISABLE` | `1` | Windows 版 PyTorch 不带 Triton，而 FFS 源码含 `@torch.compile`；`stereo_depth.py` 与 `app_entry.py` 都会在 `import torch` 之前设好 |
| `PYTHONUTF8` / `PYTHONIOENCODING` | `1` / `utf-8` | 避免中文路径与中文日志乱码 |
| `KMP_DUPLICATE_LIB_OK` | `TRUE` | 规避 OpenMP 重复加载导致的中断（启动器设置） |

例外：如果你自己写的脚本**先** `import torch`、**再** `import stereo_sdk`，那就需要在导入 torch 之前手动 `set TORCHDYNAMO_DISABLE=1`，否则 `@torch.compile` 装饰器会在 import 阶段报错。

# 卸载与清理

| 想清掉什么 | 做法 |
|---|---|
| 源码路线的依赖 | `python -m pip uninstall -r requirements.txt -y` |
| 以可编辑模式安装的包 | `python -m pip uninstall stereo-depth-sdk` |
| 运行数据 | 删除 `output\`、`logs\`（可安全删除，程序会重建） |
| 模型权重 | 删除 `weights\23-36-37\`（68 MB，可重新下载） |
| EXE 版 | 直接删除整个 `StereoCamera` 文件夹，不写注册表 |
