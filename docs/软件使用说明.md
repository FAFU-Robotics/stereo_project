# 软件使用说明

本文档说明三个入口（主界面 / 标定工作台 / 命令行窗口）、各自的按键与保存出来的文件，以及命令行参数与配置项。标定工作台的判读细节单独成文，见 [标定GUI使用说明.md](标定GUI使用说明.md)。

---

## 1. 三个入口

| 入口 | 打开方式 | 适合做什么 | 是否独占相机 |
|---|---|---|---|
| **主界面 Stereo Viewer**（默认） | 双击 `StereoCamera.exe`，或 `python app_entry.py` | 看彩色 / 深度 / 点云，保存快照，跳到标定 | 点「开始串流」后独占 |
| **标定工作台**（四页流程） | 主界面左侧「标定工作台」按钮，或 `python app_entry.py --gui`，或 `python tools\calib_gui.py` | 采集标定图、算标定、检查校正、保存参数 | 打开相机后独占 |
| **命令行实时窗口** | `python main.py`（可加 `--mode depth` / `--mode pointcloud`），或 `tools\启动_普通权限.bat` 菜单 | 无人值守跑固定帧数、脚本化验证、老式 OpenCV 窗口 | 运行时独占 |

相机是独占设备：同一时刻只能有一个入口在出图。切换入口前，先在原入口「停止串流」或关闭窗口。

## 2. 主界面（Stereo Viewer，默认入口）

### 2.1 界面分区

| 区域 | 内容 | 说明 |
|---|---|---|
| 左上「设备」 | 未连接 / 正在连接 / 串流中，分辨率与帧率 | 连接状态与实时帧率 |
| 左下「推理档位」 | 档位下拉框 + 深度范围滑条 | 换档会重新加载模型（数秒）；滑条只改显示与点云的深度范围 |
| 左下三个按钮 | 标定工作台 / 环境自检 / 模型自检 | 打开标定工作台前会先停掉串流，把相机让出去 |
| 中间 | `2D` / `3D` 两个标签；`彩色` / `深度` / `视差` 勾选框 | 2D 看两幅图，3D 看点云 |
| 右侧「标定结果」 | 当前 `stereo_calib.yaml` 的摘要（RMS、基线、内参等） | 只读展示 |
| 右侧「采集与快照」 | 列表 + 「刷新」「打开目录」 | 扫描 `output\calib`（标定采集）与 `output\captures`（快照），点条目回看 |
| 右侧「通知」 | 运行日志 | 连接、保存、出错都会写在这里 |
| 右上角 | 「开始串流」/「停止串流」 | 唯一的出图开关 |

### 2.2 开始串流

1. 点右上角「开始串流」。状态依次变为「正在连接…」→「串流中」，并显示分辨率与帧率。
2. 首次进入深度或点云视图时才会加载推理模型，需要数秒；这段时间画面可能只有彩色。
3. 点「停止串流」释放相机。关闭窗口也会释放。

### 2.3 视图与鼠标操作

- `2D` 标签下，勾选「彩色」看左右原图，勾选「深度」看伪彩深度，勾选「视差」看视差图；可同时勾选。
- `3D` 标签下显示彩色点云：**左键拖动旋转、右键拖动平移、滚轮缩放**。
- 画面上的鼠标移动会显示当前位置的读数（悬停提示）。
- 深度伪彩的配色随「推理档位」里的深度范围滑条变化：近处偏暖、远处偏冷。

### 2.4 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 暂停 / 继续画面刷新 |
| `s` / `S` | 保存当前快照到 `output\captures\` |
| `1` | 切到彩色视图 |
| `2` | 切到深度视图 |
| `3` | 切到 3D 点云视图 |

### 2.5 采集、快照与标定

- **快照**：按 `s` 后，在 `output\captures\` 下新建一个时间戳目录，内容与命令行窗口保存的一致（见第 5 节）。
- **回看**：右侧「采集与快照」列表会同时列出 `output\calib` 下的标定采集与 `output\captures` 下的快照；选中条目即回看，点「打开目录」在资源管理器中定位。
- **标定**：点左侧「标定工作台」。程序会先停止串流，再打开四页式标定 GUI；标定完成后回到主界面，右侧「标定结果」会刷新。
- **自检**：左侧「环境自检」检查路径、依赖与 CUDA（不需要相机）；「模型自检」加载权重并对合成图推理一帧（不连相机，需要显卡）。

### 2.6 相机独占提醒

串流期间，其他程序（浏览器视频页、会议软件、另一个本程序窗口、标定工作台）都无法打开相机。若提示「连接失败」，先停止串流或关闭另一个窗口。

## 3. 命令行实时窗口（main.py / 启动器）

启动器 `tools\启动_普通权限.bat` 的菜单项 `[2]`~`[4]` 与 `python main.py` 系列命令都会打开这类 OpenCV 窗口。它们与主界面共用同一套推理链路，但界面是 OpenCV 窗口，不是 Tk。

### 3.1 按键

以下按键表来自 `runtime.py`（启动器与菜单会自动加 `--use-runtime`）：

| 键 | 作用 |
|---|---|
| `q` / `ESC` | 退出当前模式 |
| `空格` | 暂停 / 继续画面刷新（推理继续在后台跑） |
| `i` | 在控制台打印 `stats()` 与当前参数 |
| `p` 或 `s` | 保存当前结果到 `output\captures\` |
| `[` / `]` | 缩短 / 扩大深度范围（zmin、zmax 同步按比例调整） |
| `o` | 重新打开被关掉的 3D 点云窗口（仅点云模式） |
| `m` | 循环切换推理预设（精确 → 平衡 → 快速） |

> 若直接执行 `python main.py` 而不加 `--use-runtime`，走的是旧链路，按键为 `q/ESC`、`p/空格`、`s`、`i`、`h`、`o`，没有 `[`、`]`、`m`。

**关掉 3D 窗口不等于退出程序**：点云演示会继续，按 `o` 可以再打开。

## 4. 标定工作台

四页流程：**采集 → 标定 → 检查校正效果 → 保存参数**。打开方式见第 1 节。操作细节与判读标准见 [标定GUI使用说明.md](标定GUI使用说明.md)。

要点：

- 采集页需要相机，其余三页是纯 CPU 计算。
- 保存会写入 `calibration\stereo_calib.yaml`，旧文件自动归档到 `calibration\archive\`。
- 保存后主界面会重新读取标定，无需重启。

---

## 5. 保存出来的东西

保存快照后，`output\captures\` 下会新建一个毫秒级唯一目录，命名规则是 `时间戳_毫秒_cloud`，例如 `20261028_171235_486_cloud`。

| 文件 | 内容 | 单位 / 类型 |
|---|---|---|
| `left_raw.png` | 左目**已校正**图像 | uint8 BGR |
| `right_raw.png` | 右目已校正图像 | uint8 BGR |
| `disparity.npy` | 视差 | float32，像素（模型分辨率） |
| `depth_meter.npy` | 深度 | **float32，米**，0 = 无效 |
| `valid.npy` | 有效掩码 | bool |
| `depth_meter.txt` | 有效像素占比与中位深度 | 文本 |
| `cloud.ply` | 彩色点云，ASCII 格式 | 米；相机系 x 右、y 下、z 前；颜色 RGB |
| `meta.txt` | 序号、预设、各阶段耗时、形状、保存时间 | JSON |

> **坐标系注意**：保存的 PLY 是相机光学坐标系（**y 向下**）。Open3D / MeshLab 默认把 +y 当“上”，所以打开后看起来上下颠倒，这是查看器的预期行为，不是数据错了。3D 窗口内部只在显示时翻转 y，不改数据。

## 6. 命令行参数

`main.py` 的全部参数（`python main.py -h` 可查）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--mode` | `preview` | `preview` / `depth` / `pointcloud` |
| `--config` | `<根>/config.yaml` | 改用别的配置文件 |
| `--use-runtime` | 关 | 走新链路（菜单与启动器默认加） |
| `--list` | — | 只列出相机设备后退出 |
| `--no-display` | 关 | 不开窗口，用于自动化 |
| `--max-frames N` | 0（不限） | 跑满 N 帧自动退出 |
| `--duration S` | 0（不限） | 跑满 S 秒自动退出 |
| `--save-snapshot` | 关 | 运行中保存一次左右原图 |
| `--display-scale` | 取配置 | 显示缩放系数 |
| `--threaded` | `auto` | `auto` / `on` / `off`，三线程流水线开关 |
| `--scale` | 取配置 | 覆盖 `ffs.scale`（0.5 明显提速） |
| `--valid-iters` | 取配置 | 覆盖 `ffs.valid_iters` |
| `--max-disp` | 取配置 | 覆盖 `ffs.max_disp`（决定最近可测距离） |
| `--zmin` / `--zmax` | 取配置 | 覆盖 `pointcloud.zmin_m` / `zmax_m`（米） |
| `--voxel` | 取配置 | 体素下采样边长（米），0 = 不采样 |
| `--point-size` | 2.0 | Open3D 点大小 |
| `--cloud-window` | 900 | 3D 窗口边长（像素） |
| `--no-cloud-window` | 关 | 不开 Open3D 窗口 |

`app_entry.py` 的入口参数：

| 参数 | 作用 |
|---|---|
| `--where` | 打印路径解析结果后退出（排错第一条命令） |
| `--selftest` | 环境自检（路径 / 依赖 / CUDA，不需要相机） |
| `--gui` | 直接进标定工作台 |
| `--gui-selftest` | 只把主界面建出来再自动关掉（打包验收用） |
| `--calib-selftest` | 只把标定工作台建出来再自动关掉 |
| `--model-selftest` | 不连相机，加载权重并对合成图推理一帧 |
| `--version` | 打印版本 |

常用组合：

```bat
REM 快速档全链路（约为默认的 2 倍速）
python main.py --mode pointcloud --scale 0.5 --valid-iters 4

REM 采集 10 秒后自动退出，用于无人值守验证
python main.py --mode depth --no-display --duration 10

REM 只看相机设备清单
python main.py --list
```

## 7. 配置文件改哪里

配置文件是根目录的 `config.yaml`，分为 8 段：`project` / `camera` / `depth` / `calibration` / `ffs` / `pointcloud` / `runtime` / `gui`。最常改的四项：

| 想改什么 | 改哪 | 注意事项 |
|---|---|---|
| 相机索引 | `camera.single_index`（左右拼接模式） | 笔记本内置摄像头通常是索引 0，**不要**当成双目相机 |
| 深度范围 | `pointcloud.zmin_m` / `zmax_m` | 与 `depth` 段的范围独立，改完只影响点云与伪彩 |
| 推理档位 | `ffs.scale` / `ffs.valid_iters` | 改 `scale` **不需要**重标定；改**分辨率**必须重标定 |
| 界面语言 | `ui.language` | `zh` / `en`；也可用 `--lang en` 临时覆盖 |
| 标定是否生效 | `depth.calibrated` | 改成 `false` 会退回厂家标称值（基线 60 mm），此时**禁止测量** |

`gui.preview_fps` 与 `gui.cv_threads` 控制标定工作台的预览帧率与 OpenCV 线程数：机器发烫或光标发涩时，把 `preview_fps` 调小（例如 6）、`cv_threads` 保持 1。

`config.yaml` 内每条配置都带注释说明来源与实测依据，改之前请先读注释。

## 8. 出问题先做这三件事

1. **看日志**：`logs\app-日期.log`，最后几十行通常直接给出原因。
2. **跑自检**：主界面左侧「环境自检」，或命令行 `python app_entry.py --selftest`。它会指出是路径、依赖还是 CUDA 的问题。
3. **查清单**：[常见问题.md](常见问题.md) 按现象索引。

## 9. 已知限制

| 限制 | 说明 |
|---|---|
| 同一时间只能有一个程序占用相机 | 浏览器视频页、会议软件、另一个本程序窗口都会导致“打不开相机” |
| EXE 只在开发机上验证过 | 干净 Windows 机器未验证，见 [../packaging/打包测试报告.md](../packaging/打包测试报告.md) |
| 单文件 EXE 未做 | torch 的 CUDA 库约 4.3 GB，单文件模式每次启动都要解压，不实用 |
| 3D 交互未做自动化测试 | 鼠标旋转、平移、滚轮缩放需人工操作 |
| 主界面与标定工作台不能同时出图 | 两者都要独占相机；切换前需先停止串流 |
