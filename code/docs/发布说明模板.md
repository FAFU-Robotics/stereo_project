## 下载与使用

| 文件 | 说明 |
|---|---|
| `StereoCamera-v0.3.0.7z.001` / `.002` / `.003` | 必须**三个全部下载**，用 7-Zip 解第一卷 |
| `SHA256SUMS.txt` | 校验用 |

解压后双击 `StereoCamera.exe`，**不要只拷 exe**。步骤见 [安装指南.md](安装指南.md) 路线 A。

## 必须说明的四件事

1. **许可限制**：内置的 Fast-FoundationStereo 代码与权重为 NVIDIA Source Code License，**仅限研究/评估用途，不可商用**。本项目的自有代码为 MIT。依据见 [../NOTICE.md](../NOTICE.md)。
2. **硬件前提**：需要 NVIDIA 显卡与支持 CUDA 12.8 的驱动（`nvidia-smi` 中 CUDA Version ≥ 12.8）。没有 NVIDIA 显卡时，预览与标定可用，**推理与点云不可用**。
3. **未验证项**：干净 Windows（未装 Python）机器未验证；标定 GUI 四页未逐项人工点测；数小时连续运行与显存泄漏未测。详见 [../packaging/打包测试报告.md](../packaging/打包测试报告.md)——未验证的项目不会写成“已支持”。
4. **已知限制**：标定与分辨率绑定（改分辨率必须重标定）；精确档约 3.9 FPS，不适合高速运动；同一时间只能有一个程序占用相机。

## 校验方式

```powershell
Get-FileHash .\StereoCamera-v0.3.0.7z.001 -Algorithm SHA256
```

与 `SHA256SUMS.txt` 中对应行逐字符比对。
