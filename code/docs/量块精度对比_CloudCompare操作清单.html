0 · 开工前 5 项硬检查（任一不过就不要采集）

  • 单位 = 米。打开 PLY，首部 comment 行或坐标数值量级应在 0.1–3 之间；若出现 200–3000 这种量级 → 是毫米，先换算，否则后面全错。
  • 尺度自检。先只载入一片点云，用 Tools ▸ Point picking（两点标签）量物块一条已知棱，读数与千分尺实测之差应 < 2%。不通过就停，这是唯一能在做实验前发现系统错的方法。
  • 点云由校正后 P1 反投影。本项目已标定值：f_rect = 547.017 px、B = 64.8907 mm、Q[2][3] = 0.0154105。用原始 K 反投影会让鱼眼物块弯曲。
  • RealSense 后处理滤波状态已记录：spatial / temporal / hole-filling 全关 或 全开，且两台相机同等处理，写进本页脚注。
  • 物块真值已测。千分尺在 5 个位置各测一次，记均值与极差：均值 mm，极差 mm，测量温度 ℃。量块取两工作面法向距离（不是棱长）。

为什么必须重复 10 次：单次结果无法区分「系统误差」与「这一次的随机噪声」。10 次才能算出重复性标准差，这也是唯一能证明“稳定”的证据。

2 · CloudCompare 六步操作（每片点云各做一遍）

Step 1 · 导入

  • File ▸ Open 载入 PLY。两片云不要合并，合并会丢失“这片来自哪台相机”的信息。
  • 选中云，在左下 Properties 核对点数与包围盒边长，确认尺度正确。

Step 2 · 裁出两个工作面

  • 选中云 → Edit ▸ Segment（剪刀图标）→ 左键勾多边形、右键闭合 → 点 segment in 保留内部。
  • 面 A：只留一个工作面，边缘倒角往里收 2 mm，避免倒角把平面 RMS 拉高。
  • 面 B：换视角旋转后同样裁一次，得到独立的两片云。裁完点 Enter 结束。
  • 每个面保留点数：≥ 5000 点（少于这个数，拟合随机性会盖过真实误差）。

Step 3 · 拟合面 A

  • 选中面 A 云 → Tools ▸ Fit ▸ Plane。
  • 从 Console 抄下 plane fitting RMS（单位＝点云单位，即米，记表时 ×1000 换成 mm）。
  • 拟合平面会作为子实体挂在云下面，是一个三角网格——下一步要用它。

Step 4 · 量厚度（面 B 点 → 面 A 平面）

  • 同时选中「面 B 的点云」＋「面 A 的拟合平面」→ Tools ▸ Distances ▸ Cloud/Mesh Dist.
  • 勾选 signed distances（云到网格可带符号，这是与云-云距离的关键差别）。
  • 选中面 B 云 → 左下 Properties ▸ Scalar Fields → 读 mean（带符号＝实测厚度） 与 std。
  • 顺手看一眼直方图：出现双峰 → 匹配出了条纹误配，这片云作废重采。
这一步最容易出错的地方：拟合平面网格的范围由面 A 点云自动决定。若面 B 的点超出该网格边界，边界点会被算到最近三角形边缘上，mean 与 std 会同时虚大。处置：只保留面 B 落在面 A 覆盖范围内的中心区域，或裁掉面 B 外圈 15%。CloudCompare 官方文档对此的原文提醒是「参考云的范围应大于被比较云，以避免边界上的虚假大距离」。

Step 5 · 反向再做一次（自洽性检查）

  • 反过来：拟合面 B 的平面，用面 A 的点去量它，得第二个厚度值。
  • 两次之差记入表内「自洽差」列。这个差值代表方法本身的不确定度，理想应 < 2 mm。

Step 6 · 分区重做（中心 / 边缘）

  • 同一片云里把物块切成「中心 1/3」与「外圈」两块，各重跑 Step 3–4。
  • 中心与边缘的 ΔD 之差，就是畸变残差的直接证据——这比任何 RMS 数字都更能说明问题。

4 · 判据（列表值与换算）

深度误差与视差误差的关系为 σz = Z²·Δd / (f·B)。代入本项目标定值 f = 547.017 px、B = 64.8907 mm：

表中「应 ≤」一列以有效匹配精度 0.3 px 为假设推算，属于可调目标值，不是行业标准。若实测明显优于它，说明你的匹配优于 0.3 px；若明显差于它，把实测 σz 代回公式反推实际 Δd = σz·f·B / Z²，就能判断问题在匹配还是在标定。

  • 同一档 10 次 ΔD 的标准差 ≤ 2 mm（重复性合格）
  • 中心区 ΔD 与边缘区 ΔD 之差 ≤ 5 mm（畸变残差可接受）
  • 正反两次厚度差 ≤ 2 mm（方法自洽）
  • 面 A／面 B 的拟合 RMS 与该距离的 σz 同量级（不应大一个数量级）
