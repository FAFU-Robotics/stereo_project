# ---- 深度学习框架（必须 cu128 源；不要用默认 PyPI 的 CPU 版）----
#  安装命令（换机复现时照抄）：
#    pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cu128
#
#  为什么是 2.9.1 而不是 2.8.0：
#    RTX 5060 是 Blackwell **sm_120**，cu124 及更早的预编译内核里没有它，必须 cu128+。
#    而 cu128 索引里 2.8.0 只提供 cp39~cp313，**没有 cp314**；
#    Python 3.14 在 cu128 线上只有 2.9.0 / 2.9.1 带 cp314 wheel。
#
#  ⚠️ Python 3.14 专属问题（已在 stereo_depth.py 内解决，不要删那段代码）：
#     torch 2.9.1 的 torch.compile() 在 sys.version_info >= (3,14) 时直接
#     raise RuntimeError("torch.compile is not supported on Python 3.14+")。
#     FFS 的 core/submodule.py:376 是 @torch.compile —— 装饰器在 import 阶段求值，
#     不处理就会让 `import core.foundation_stereo` 直接失败。
#     → stereo_depth.py 在 import torch 后把 torch.compile 换成恒等装饰器（语义等价）。
# =============================================================================
