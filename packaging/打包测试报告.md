无。本次在这台机器上没有发现 EXE 启动失败、推理失败或相机打不开。

## 未验证

| 项目 | 原因 |
|---|---|
| 没有安装 Python 的另一台 Windows | 没有第二台电脑 |
| 标定 GUI 四页逐项点击（采集、计算、检查、保存） | 只做了窗口能创建并自动关闭 |
| 3D 窗口里的鼠标旋转、按 O 重开 | 日志确认窗口已创建，没有人工操作窗口 |
| 连续运行数小时、以及显存是否缓慢泄漏 | 只测了约 40 秒内存 plateau |
| 没有 NVIDIA 驱动、或不是 sm_120 的显卡 | 本机驱动可用。别的显卡未测 |
| 单文件 EXE | 没有做。torch 的 CUDA 库约 4 GB，单文件每次启动都要解压 |

## 打包产物

- 方式：PyInstaller 6.22.3，目录模式（onedir），无控制台，关闭 UPX
- 入口：`app_entry.py`
- 体积：约 5.0 GB（其中 torch CUDA 运行库约 4.3 GB）
- 双击后出现功能菜单，不是直接进某一个模式
- 重复打包：在项目目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File packaging\build_exe.ps1`
